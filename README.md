# whoami

Personal portfolio site — [rhlbzz.com](https://rhlbzz.com)

A single-page personal website built with Vue, used to introduce myself professionally and showcase a curated selection of my work.

## What it includes

- A short personal introduction
- Selected projects, presented as case studies for specific skills
- A direct link to my CV
- Contact information

## Tech stack

- Vue
- Vite
- Vue Router
- UnoCSS

## Deployment

Every push to `main` triggers a CI/CD pipeline that builds the site and deploys it via Vercel.
